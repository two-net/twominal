# Links at cells, as the mouse finds them (TERM-20): the one a program made of the cell (OSC 8),
# or else a URL in the text around it. No terminal is the model for what a URL is: this follows
# DESIGN.md §3 *URLs*, which Alacritty and kitty are close to. Which links may open is not the
# screen's, and is tested with `opening` in src/tests.rs.

## A URL in the text is a link to where it says
size 40x2
send see https://example.com/a for more
hover 1;10
target https://example.com/a
hovered
|....*********************...............|
|........................................|

## A URL keeps the brackets it opened

## A link in Markdown is the URL in its parentheses
size 40x1
send [the docs](https://a.io/b).

## Quotes and angle brackets end a URL
size 40x1
send <https://a.io/x> "https://b.io/y" 'c'
hover 1;3
target https://a.io/x
hover 1;20
target https://b.io/y

## A single quote after a URL is taken off
size 40x1
send 'https://a.io/x'

target https://a.io/x

## The scheme is found in any letter case, and the target keeps it
size 20x1

## A URL goes on to the end of its run, another scheme and all
# As in Alacritty: a URL may hold another, as a redirect does.
size 40x1
send http://a/?to=http://b,http://c
hover 1;25
target http://a/?to=http://b,http://c

## A blank parts two URLs
size 30x1

## Mail and files are URLs too
size 40x2
send mailto:me@a.io file:///tmp/a.txt
hover 1;3
target mailto:me@a.io
hover 1;20
target file:///tmp/a.txt
