# What is ignored (REL-02): whatever DESIGN.md §3 does not list, as ECMA-48 asks. Each case
# prints a before and the rest after, and nothing else may change.

## SGR with an intermediate is not SGR
# xterm's modifyOtherKeys and its query. A program that wants its keys told apart has the
# kitty keyboard protocol (DESIGN.md §3).
size 10x2
send a\e[>4;1mb\e[?4mc
screen
|abc       |
|          |
styles
|..........|
|..........|
cursor 1;4

## Mode 12 is ignored, so cnorm keeps the blink
# xterm-256color's cnorm turns the blink off with 12 before it shows the cursor, and ncurses,
# vim and top send it. The blink is the settings' and DECSCUSR's (DESIGN.md §3).
size 10x2
send a\e[5 q\e[?12l\e[?25hb
screen
|ab        |
|          |
cursor 1;3
mode cursor_style blinking bar
mode cursor_visible on

## Other operating system commands are ignored
# The icon label (OSC 1), shell marks (133), notifications (9, 777), iTerm2's own (1337), the
# pointer's shape (22) and the dynamic colors that are not the theme's (13 to 19). A report of
# the shell integration is a report only with the session's nonce, and these cases have none.
size 10x2
send a\e]1;icon\ab\e]133;A\ac\e]9;hi\ad\e]777;notify;t;b\ae\e]1337;SetMark\af\e]22;hand\ag
send \e]13;?\a\e]17;#ff0000\ah\e]2222;n1;ready\ai
screen
|abcdefghi |
|          |
cursor 1;10
