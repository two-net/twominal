# Find (TERM-18, TERM-19): what a search finds on the screen and in the scrollback, which match
# is current, and how the matches keep up with output. No terminal is the model here: what find
# takes follows DESIGN.md §3 *Find*, and its matches are those the `regex` crate finds in each
# line, as copying gives the line.

## Every match is found, on the screen and in the scrollback
size 6x2
send foo\r\nbar\r\nfoo
find foo
found 2 of 2

## Find starts at the bottom, goes up, and round the ends
size 6x3
send ab\r\nab\r\nab
find ab
found 3 of 3
next up
found 2 of 3
next up
found 1 of 3
next up
found 3 of 3
next down
found 1 of 3

## The spaces at the end of a line are not part of it
size 6x2

## Two matches in the characters of one cell are one
# `.` finds the e and the mark joined to it apart, and the cell is the first one's.
size 4x1
send ae\xcc\x81b
find regex .
found 3 of 3
matches
|**#.|

## A regular expression finds what it matches, from the start of each line to its end

find regex ^42[0-9]{2}$

## Empty matches are skipped
size 6x1
send abc
find regex x*
found 0

## Plain text finds the characters a pattern gives a meaning to
size 12x1
send a.b+c*d?(e)
find .b+c*
matches

## Output adds matches
size 6x2
find foo
found 0
send foo
found 1 of 1

## Output that writes over a match takes it away
size 8x1
send foo bar
find foo
found 1 of 1
send \rx
found 0

## Output that erases a match takes it away
size 6x2
send foo\r\nfoo
find foo
found 2 of 2
send \e[2J
found 0

## A line that stops wrapping is searched again from where it ends
# Erasing the last cell of a row ends its line there, so the next row starts one of its own.
size 2x2
send abcd
find regex ^cd
found 0
send \e[1;2H\e[X
found 1 of 1
matches

## The current match stays on its text while output scrolls it
size 6x2
send foo\r\nbar\r\nfoo

## When the current match goes, the match before it is current
size 6x3
send foo\r\nfoo\r\nfoo
find foo
next up
found 2 of 3
send \e[2;1Hx
found 1 of 2

## The same search again keeps the current match
size 6x3
send foo\r\nfoo\r\nfoo
find foo
next up
found 2 of 3
find foo
found 2 of 3

## A new search goes on from where the search before it was
# The current match is the last that starts at or before it: the same match while it still
# matches, as a query is typed, and else the one above it.
size 8x3
send food\r\nfood\r\nfood
find foo
next up
found 2 of 3
find food
found 2 of 3
find ood
found 1 of 3

## A query that finds nothing on the way keeps the place
size 8x3
send food\r\nfood\r\nfood
find foo
next up
found 2 of 3
find foox
found 0
find foo
found 2 of 3

## A pattern that is none on the way keeps the place
size 8x3
send food\r\nfood\r\nfood
find regex fo
next up
found 2 of 3
find regex fo[
found invalid
find regex fo[o]
found 2 of 3

## Find looks from the row it is given when it is new
# The suite gives the screen's last row, as a view at the bottom does, so the newest match
# above it is current, and the matches below what output brings later come after it.
size 6x3
find foo
send foo\r\nfoo
found 2 of 2
