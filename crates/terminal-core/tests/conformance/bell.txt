# The bell (TERM-12, TERM-21). BEL rings it, and the Tab flashes it, plays it or not, as the
# Bell setting says. Each BEL rings once: the Tab is the one to ring a flood of them once.

## BEL rings the bell, and takes no cell
size 10x2
send a\ab\a\a
bell
bell
bell
screen
|ab        |
|          |
cursor 1;3

## BEL inside a control sequence rings the bell too
# vte, as xterm, carries out a C0 control inside a CSI and goes on with the CSI.
size 10x1
style b bold
send \e[1\amx
bell
styles
|b.........|

## BEL that ends an OSC rings nothing
size 10x1
send \e]2;x\a\e]133;A\a
title x
screen
|          |
