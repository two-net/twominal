# Colors and text attributes: SGR (TERM-03 to TERM-05). Each expectation is what xterm's
# CASE_SGR and parse_extended_colors do, but for the underline's styles and color, which are
# kitty's, and the other deviations DESIGN.md §3 lists, which the comments name.

## SGR 30 to 37 color the text with the palette's first eight colors
size 8x1
style a foreground 0
style b foreground 1
style c foreground 2
style d foreground 3
style e foreground 4
style f foreground 5
style g foreground 6
style h foreground 7
send \e[30ma\e[31mb\e[32mc\e[33md\e[34me\e[35mf\e[36mg\e[37mh

## SGR 38;5 and 48;5 take any color of the palette
size 4x1
style a foreground 9
style b foreground 196
style c background 16
style d background 255
send \e[38;5;9ma\e[38;5;196mb\e[39;48;5;16mc\e[48;5;255md

|abcd|

## A color of the palette can be written in sub-parameters
# ctlseqs: CSI 38 : 5 : Ps m. xterm also takes the next parameter's: CSI 38 ; 5 : Ps m.
size 3x1
style a foreground 9
style b background 200
send \e[38:5:9ma\e[m\e[48:5:200mb\e[m\e[38;5:9mc
styles
|aba|

## SGR 38;2 and 48;2 take a 24-bit color
size 2x1
style a foreground #ff8000
style b foreground #ff8000 background #010203
send \e[38;2;255;128;0ma\e[48;2;1;2;3mb
styles
|ab|

## A 24-bit color can be written in sub-parameters, with or without the color space
# ctlseqs: CSI 38 : 2 : Pi : Pr : Pg : Pb m, where Pi is the color space. xterm takes three
# numbers alone as the color, and with four or more skips the first.
size 5x1
style a foreground #0a0b0c
style b background #010203
send \e[38:2:10:11:12ma\e[m\e[38:2::10:11:12mb\e[m\e[38:2:0:10:11:12mc\e[m\e[38;2:10:11:12md
send \e[m\e[48:2::1:2:3me
styles
|aaaab|

## A color with a number missing is ignored
size 3x1
send a\e[38;5mb\e[48;2;1;2mc
styles
|...|

## A color out of range is ignored, and the parameters it takes are used up
# xterm's parse_extended_colors takes them, whatever their values, before it checks them.
size 3x1
style b bold
send \e[38;5;256;1ma\e[m\e[38;2;256;0;0;1mb\e[m\e[48:5:300;1mc
styles
|bbb|

## A kind of color other than 2 and 5 uses up only itself
# xterm takes the 7 as the kind, which needs no numbers, and the 1 is bold.
size 1x1
style b bold
send \e[38;7;1mx
styles
|b|

## A parameter with sub-parameters it does not take is ignored
# xterm's CASE_SGR skips it: only 38 and 48 take sub-parameters there, and here 4 and 58 too.
size 2x1
style i italic

styles
|i.|
