⚡ Vim Mode Keybindings

  • Esc: Enter NORMAL mode
  • i / a: Enter INSERT mode
  • h / l: Move cursor Left / Right
  • w / b: Jump word forward / back
  • 0 / $: Jump line start / end
  • x: Delete single character
  • dd: Clear entire input line
