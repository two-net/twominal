🐟 Fish Shell Features

  • Green syntax: Valid commands
  • Red syntax: Invalid / typo commands
  • Right Arrow (→): Accept autosuggestion
  • Tab: Trigger smart completion menu
  • Ctrl + L: Clear current screen
  • Ctrl + T: Create new terminal tab

⚡ Vim Mode Keybindings

  • Esc: Enter NORMAL mode
  • i / a: Enter INSERT mode
  • h / l: Move cursor Left / Right
  • w / b: Jump word forward / back
  • 0 / $: Jump line start / end
  • x: Delete single character
  • dd: Clear entire input line
